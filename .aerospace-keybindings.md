# Keybindings — macOS (AeroSpace)

Matches `.config/i3/config` where AeroSpace supports the same actions.
`mod` is **Option (⌥)**, corresponding to physical Option on the remapped
Apple keyboard under i3/Firehawk. Command remains available for native macOS keys.

## Panes and windows

| Keys | Action |
|---|---|
| `Ctrl h/j/k/l` | Focus tmux pane / Ghostty split left/down/up/right; at the edge, the neighbouring window |
| `⌥ h/j/k/l` | Swap tmux pane left/down/up/right (terminal binding) |
| `Ctrl ⇧ h/j/k/l` | Focus desktop window left/down/up/right |
| `⌥ ↑/↓` | Focus desktop window up/down |
| `⌥ ⇧ h/j/k/l` or `⌥ ⇧ arrows` | Move desktop window |
| `⌥ q` | Close window |
| `⌥ ⇧ f` | Fullscreen |
| `⌥ ⇧ Space` | Toggle floating |

Focus wraps at the workspace edge. **Option+h/j/k/l must not be bound by
AeroSpace**: tmux needs them for pane swaps. Option+left/right deliberately stay
unbound so macOS word navigation works (an intentional difference from i3).

Tmux prefix is `Ctrl+Space`; `Ctrl+Space m` toggles mouse input.
`⌥ m` toggles pane minimize mode, `⌥ +` makes the focused pane half-width,
and `⌥ =` equalizes columns. These come from `config/shared/tmux.conf`.

## Workspaces

| Keys | Action |
|---|---|
| `⌥ 1` … `⌥ 9`, `⌥ 0` | Go to workspace 1–10 |
| `⌥ ⇧ 1` … `⌥ ⇧ 9`, `⌥ ⇧ 0` | Move window to workspace 1–10 |
| `⌥ Tab` / `⌥ ⇧ Tab` | Next / previous workspace |

## tmux session jumps

Match i3's active shortcuts. Each selects workspace 2, creates the session if
absent, then switches the tmux client. Requires tmux on AeroSpace's shell PATH
and a running client. Existing sessions are matched by exact name.

| Keys | Session |
|---|---|
| `⌥ s` | settings |
| `⌥ n` | notes |
| `⌥ a` | agency-admin (new sessions start in `$HOME/clients/client-dashboard`) |
| `⌥ p` | callisto |
| `⌥ y` | yerba-mate |

The i3 `y` binding currently tries `yerba-magic` before creating/switching to
`yerba-mate`; AeroSpace and Firehawk consistently use `yerba-mate`.

## System and AeroSpace-specific extras

| Keys | Action |
|---|---|
| `⌥ d` | Spotlight, if configured in macOS keyboard settings |
| `⌥ ⇧ Esc` | Lock screen |
| `⌥ ⇧ c` | Reload AeroSpace configuration |
| `⌥ w` | Horizontal accordion (closest equivalent to i3 tabbed layout) |
| `⌥ ⇧ -` / `⌥ ⇧ \` | Split horizontal / vertical |
| `⌥ r` | Resize mode: h/l change width, k/j change height; Enter/Esc exits |

Layout and resize shortcuts above are retained macOS extras; i3's corresponding
bindings are currently commented out. `⌥ e` is not bound.

Spotlight is not an AeroSpace binding: assign Option+d in macOS settings rather
than synthesizing Command+Space while Option is held. Disable macOS input-source
shortcuts (IDs 60/61) if they consume the tmux Ctrl+Space prefix, and Dictation's
double-Control shortcut (ID 164) if needed. This repo's portable setup does not
automatically configure those system hotkeys or Ghostty's Option+Enter shortcut.

## Platform differences

- i3's tiling/floating focus toggle and parent focus have no direct AeroSpace equivalent.
- i3's rofi window menu, power menu, empty-workspace helper, monitor recovery,
  and power-profile scripts are Linux-specific and are not bound here.
- Native macOS media/brightness keys and Command+Shift+3/4 screenshots remain intact.
- Simulator/emulator windows retain their macOS-specific floating rules.
